# Final Handoff

This folder contains final, shareable report-building artifacts.

## Primary files

- `isys812_report_core_inputs.md`  
  Core report sections: driving question, dataset block, five analysis questions, cleaning steps, sample rows.

- `report_and_presentation_master.md`  
  Consolidated narrative for report/presentation structure, evidence references, strategic layer, and supporting file map.

- `isys814-finaProjectReport_group2.docx`  
  Final report working document (protected deliverable).

- `isys814-finalProjectReport_group2.pdf`  
  Final report PDF deliverable (protected deliverable).

- `presentations/Finalpresentation.pptx`  
  Final presentation deck.

- `submission_sources_group2/`  
  Analysis/source artifacts cited in the report (report files excluded).

- `submission_sources_group2.zip`  
  Zipped submission source bundle.

- `isys814-finalProjectReport_group2_with_sources_attachment.pdf`  
  Final report PDF with `submission_sources_group2.zip` attached as a file-icon annotation on the sources page.

## Usage

1. Use `isys812_report_core_inputs.md` for rubric-required sections.
2. Use `report_and_presentation_master.md` for strategic narrative and slide/report flow.
3. Use `presentations/Finalpresentation.pptx` for the final presentation deck.
4. Keep this folder as the canonical handoff source for final assembly.

## Notes

- Disposable artifacts (checklists, stress-test scratch files, temporary helper notes) can be removed.
- Do **not** delete final report deliverables (`.docx` / `.pdf`) from this folder unless explicitly requested.
- JSON files in `submission_sources_group2` were validated as parseable before zipping.
